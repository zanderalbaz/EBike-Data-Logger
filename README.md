# E-Bike Data Logger
There are two main folders in this repo. One is intended for a developer in order to improve the solution. The other is indended for a technician to download the Java application onto their windows machine.

## Developer?
Navigate to the developer folder to see all of the code. The ESP32 sensor code is located in the ESP32-sensor-code folder. The Java application, which was developed with IntelliJ, is located in the 495_prototype folder. The most up-to-date machine learning script is "Bike classification final.ipynb". You will need to install Jupyter Notebook in order to make changes. 

## Technician?
Navigate to the Technician folder. Download "EBikeDataLoggerAppV1.zip" onto your computer. Unzip and extract all of the files. The application can be launched using "EBikeDataLoggerAppV1.exe". You may also create a shortcut to this file for ease of access.

For more information, check out the "E-Bike Data Logger Documentation.docx" file.
